# desk

Селекция агента / треда / schedule / webhook и live-статусы workspace. Имя слайса, не термин продукта.

**API:** `useDesk*`, `useSelect*`, `useOpenAgent`, `useAgentLiveStatus`, `DeskSync`, store types.

**Server:** desk events / SSE (`adapters/desk-events.adapter.ts`), thread/workspace HTTP.
