# Bug: map не принимает инструкцию обработки

Источник: самотест агента, память `e5d37a74`, п.4. Статус: open.

## Наблюдение

`map(["red","green","blue"])`: один элемент вернулся эхом, второй — эссе на 66 токенов, третий — эхом. Расход токенов на элемент не контролируется.

## Код

- `packages/harnesys/src/adapters/actions/graph-control.ts:9-43`: вход только `items`.
- `packages/harnesys/src/application/graph-map.ts:168-174`: промпт воркера зашит, `mapItemInput` без инструкции.
- Спека ноды: `MapNodeSpec` в `graph-map.ts:21-30`, пресеты агентов (`apps/studio/assets/presets/agents/*.json`, секция `## Graph map and wait`).

## Направление

Добавить `instruction` (шаблон с `$item`/`$index`) и лимит токенов на элемент. Трогает схему ноды `control:map`, тул `map`, форму графа в Studio, тексты пресетов. Отдельная задача с обсуждением, не быстрый фикс.

## Приёмка

Одинаковые элементы при одной инструкции дают предсказуемый объём ответа; лимит режет эссе до заданного размера.
