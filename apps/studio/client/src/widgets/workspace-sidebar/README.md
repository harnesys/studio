# workspace-sidebar

Шапка: полоса из 5 слотов (WORKSPACE_TAB_CAP) — аватары воркспейсов на столе (shift/control — мультиселект), призраки off-desk воркспейсов (клик — вернуть на стол), пустые слоты с «+» (клик — создать), меню ⋯. Секции: Inbox, агенты, files, schedules, webhooks, create workspace.

**Зависит от:** `features/desk`, `create-workspace`, `manage-agent`, `manage-schedule`, `open-file`.
