# Harnesys 0.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Каркас `packages/harnesys@0.1.0`: полные типы `docs/01`–`05` (+ порты под сигнатуру `05`), `defineAgent`, `InMemoryRuntimeState`, `createRuntime` skeleton с `NotImplementedError` на executor/session методах.

**Architecture:** Clean/Hexagon без use-case классов. `domain/` держит типы и `defineAgent`. `ports/` объявляет `RuntimeState` и контракты wiring. `application/create-runtime.ts` собирает handle. `adapters/in-memory-runtime-state.ts` реализует persist-семантику sequence upsert/ignore. Публичный barrel: `packages/harnesys/index.ts`.

**Tech Stack:** TypeScript (strict, bun types), Bun, biome (root `biome.json`). Unit-тестов нет.

**Spec:** `docs/superpowers/specs/2026-08-30-harnesys-0.1.0-design.md`

## Global Constraints

- SoT контракта: только `docs/` (поля/union только оттуда; без index-access типов `T['x']`).
- Файл ≤ 300 строк (`AGENTS.md`, biome `noExcessiveLinesPerFile`).
- Тесты запрещены: не создавать `*.test.ts` / `*.spec.ts`; verification = `tsc` + biome.
- Не копировать `apps/studio/harnesys-stub`.
- `ai` / `@ai-sdk/*` не в public exports.
- Dependencies в `package.json` не чистить в этом плане; только `version` / `exports` / scripts при необходимости.
- Повторный `commit` с тем же `sequence` = upsert/ignore (ошибку не бросать).

### Task 4: `InMemoryRuntimeState`

**Files:**
- Create: `packages/harnesys/src/adapters/in-memory-runtime-state.ts`

**Interfaces:**
- Consumes: `RuntimeState`, `Snapshot`, `Event`, `CommitMeta`
- Produces: `class InMemoryRuntimeState implements RuntimeState`

- [ ] **Step 1: Implement adapter**

```ts
export class InMemoryRuntimeState implements RuntimeState {
  readonly sessionId: string
  private snapshot: Snapshot | null = null
  private readonly events: Event[] = []
  private readonly sequences = new Set<number>()
  private readonly children = new Map<string, InMemoryRuntimeState>()

  constructor(sessionId: string) {
    this.sessionId = sessionId
  }

  async load(): Promise<Snapshot | null> {
    return this.snapshot
  }

  async commit(
    snapshot: Snapshot,
    events: readonly Event[],
    meta: CommitMeta,
  ): Promise<void> {
    if (this.sequences.has(meta.sequence)) {
      // upsert/ignore: replace snapshot, do not append duplicate sequence events
      this.snapshot = snapshot
      return
    }
    this.sequences.add(meta.sequence)
    this.snapshot = snapshot
    for (const event of events) {
      this.events.push(event)
    }
  }

  child(spawnId: string): RuntimeState {
    const existing = this.children.get(spawnId)
    if (existing) return existing
    const child = new InMemoryRuntimeState(`${this.sessionId}:${spawnId}`)
    this.children.set(spawnId, child)
    return child
  }

  /** Test/debug helper; not required on RuntimeState port */
  getCommittedEvents(): readonly Event[] {
    return this.events
  }
}
```

Семантика same-`sequence`: snapshot обновляется (upsert), events для этого sequence повторно не пишутся (ignore). Ошибку не бросать.

```ts
export async function createRuntime(
  options: CreateRuntimeOptions,
): Promise<RuntimeHandle> {
  const wiring = options
  const ni = (method: string) => {
    throw new NotImplementedError(method)
  }

  return {
    run: async () => ni('run'),
    start: () => {
      ni('start')
      return (async function* () {})()
    },
    resume: async () => ni('resume'),
    compile: () => ni('compile'),
    check: () => ni('check'),
    session: () => ni('session'),
    reloadSkills: () => ni('reloadSkills'),
    reloadMcp: () => ni('reloadMcp'),
    close: () => ni('close'),
  }

```

Замечание: TypeScript может жаловаться на unreachable после `throw` в `start`. Допустимый вариант: методы, которые должны вернуть значение, сразу `throw new NotImplementedError(...)` без fake generator. Предпочтительная форма:

```ts
run: async () => {
  throw new NotImplementedError('run')
},
start: () => {
  throw new NotImplementedError('start')
},
// ...
```

`wiring` сохранить в замыкании (`void wiring` или `Object.freeze`), чтобы опции не считались unused и были доступны будущему executor без смены сигнатуры.
