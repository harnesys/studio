# Harnesys 0.1.0 design

**Status:** draft for review  
**Package:** `packages/harnesys` @ `0.1.0`  
**SoT:** `docs/01`–`docs/05`, gate in `docs/ROADMAP.md` §0.1.0  
**Out:** executor (`run`/`start`), Expr evaluate, validate/compile (`08`), Studio cutover

## Goal

Собрать каркас библиотеки: публичные типы домена, `defineAgent`, `InMemoryRuntimeState`, `createRuntime` с полной сигнатурой из `05`. Пакет typecheck’ится и проходит biome. Повторный `commit` с тем же `sequence` = upsert/ignore.

## Decisions

| Тема | Решение |
|---|---|
| Gate unit Snapshot/commit | Не делаем `*.test.ts` / `*.spec.ts` (запрет `AGENTS.md`). Gate sequence закрываем реализацией + `tsc`/`biome`. |
| `createRuntime` surface | Полная сигнатура `docs/05`. Методы `run`/`start`/`resume`/`compile`/`check`/`session`/`reloadSkills`/`reloadMcp`/`close` бросают `NotImplementedError`. |
| `defineAgent` | Типы + identity + plain JSON (round-trip). Без Expr-парсера и без validate из `08`. |
| Типы домена | Полные типы из `01`–`05` сразу. Порты под поля `CreateRuntimeOptions` (`06`–`20`) кладём именованными контрактами из docs, чтобы позже менять в основном логику. |
| Слои | Clean/Hexagon: тонкий domain + ports из docs + application (`createRuntime`) + adapter `InMemoryRuntimeState`. Без use-case классов и без пустых обёрток. |
| Dependencies | `package.json` dependencies не чистим в 0.1.0. Ставим `version: "0.1.0"` и публичные exports. |
| Verification | `tsc` + biome на пакете. Unit-тестов нет. |

## Layout

```
packages/harnesys/
  package.json          # name harnesys, version 0.1.0, exports → index.ts
  tsconfig.json
  index.ts              # публичный реэкспорт
  src/
    domain/
      agent-definition.ts   # AgentDefinition, Node, Edge, JsonSchema, AgentModelRef, defineAgent
      expr.ts               # type Expr = string (+ слоты как документация в типах/комментариях минимума)
      snapshot.ts           # Snapshot, Cursor, CommitKind, Event envelope (поля из 04 + 22 envelope)
      middleware.ts         # GuardDecision, MiddlewareContext, Middleware
    ports/
      runtime-state.ts      # interface RuntimeState
      create-runtime.ts     # CreateRuntimeOptions, RuntimeHandle, порты models/tools/mcp/skills/…
    application/
      create-runtime.ts     # createRuntime({…}): RuntimeHandle
    adapters/
      in-memory-runtime-state.ts
```

Резать файлы по ответственности, ≤300 строк. Имена полей и union’ов только из `docs/`. Index signatures в домене не вводить сверх того, что уже в docs (`JsonSchema`, Event `metadata`).

## Public API

Из `packages/harnesys/index.ts`:

- функции: `defineAgent`, `createRuntime`, класс/фабрика `InMemoryRuntimeState`
- типы: `AgentDefinition`, `Node`, `Edge`, `Expr`, `JsonSchema`, `AgentModelRef`, `Snapshot`, `Cursor`, `Event`, `CommitKind`, `RuntimeState`, `GuardDecision`, `Middleware`, `MiddlewareContext`, `CreateRuntimeOptions`, `RuntimeHandle`, плюс порты из опций (`ModelsPort`, `ToolDefinition`, …) ровно под имена в `05`/`06`–`20`

`ai` / `@ai-sdk/*` в публичных exports не появляются (`01`, ROADMAP 1.0).

## `defineAgent`

```ts
function defineAgent(def: AgentDefinition): AgentDefinition
```

Поведение 0.1.0: принять definition, вернуть plain JSON-совместимый объект (`JSON.parse(JSON.stringify(def))` или эквивалент без функций/undefined-потерь по согласованной с JSON семантикой). Валидацию графа и Expr откладываем на `08` / более поздний `defineAgent`.

## `RuntimeState` / `InMemoryRuntimeState`

Контракт (`04`):

```ts
interface RuntimeState {
  readonly sessionId: string
  load(): Promise<Snapshot | null>
  commit(
    snapshot: Snapshot,
    events: readonly Event[],
    meta: { kind: CommitKind; sequence: number },
  ): Promise<void>
  child(spawnId: string): RuntimeState
}
```

`InMemoryRuntimeState`:

- хранит последний Snapshot на `sessionId`
- копит events, переданные в `commit`
- повторный `commit` с тем же `meta.sequence`: upsert snapshot и ignore дубликата sequence (ошибку не бросать)
- `child(spawnId)`: новый `RuntimeState` (отдельное in-memory хранилище / ключ), то же правило sequence
- диск / SQL нет

`Snapshot`: полный минимальный состав из `04` (`sessionId`, `runId`, `definitionHash`, `planHash`, `sequence`, `status`, `runtimeVersion`, `initialInput`, `state`, `cursor`, `artifacts`). `Cursor` типизируем по фазам и полям из `04`, без выдуманных attemptId.

`Event`: envelope stub из `22` (`eventId`, `type`, `timestamp`, `sessionId`, `runId`, `agentId`, `sequence`, `causationId`, `correlationId`, `metadata?`). Catalog типов событий в 0.1.0 не реализуем как runtime enum обязательный для commit.

## `createRuntime`

Принимает `CreateRuntimeOptions` как в `05` (models, tools?, mcp?, skills?, agents, permissions?, paths?, artifacts?, nodes?, middleware?, toolMessages?, …). Сохраняет wiring внутри handle.

Методы `RuntimeHandle` существуют в типах и на объекте; тело 0.1.0:

| Метод | 0.1.0 |
|---|---|
| `run` / `start` / `resume` / `compile` / `check` / `session` / `reloadSkills` / `reloadMcp` / `close` | `throw new NotImplementedError(method)` (один тип ошибки пакета) |

Порты (`ModelsPort`, tools, MCP, skills, permissions, paths, artifacts): типы по docs соответствующих номеров, достаточные для компиляции опций. Реализации registry/execute не входят в 0.1.0.

## Verification

1. `bunx tsc --noEmit` (или эквивалент из `packages/harnesys/tsconfig.json`)
2. biome check/format на затронутых файлах пакета
3. Ручная уверенность: код `InMemoryRuntimeState.commit` явно обрабатывает same-`sequence` как upsert/ignore

## Scope boundary

Входит: типы `01`–`05` + порты под сигнатуру `05`, `defineAgent`, `InMemoryRuntimeState`, skeleton `createRuntime`, `version`/`exports`.

Не входит: `run`/`start` executor, Expr evaluate, `08` codes, HITL/`Command`, session/`AgentRun`, permissions runtime, Studio wiring, unit-тесты, чистка AI SDK deps, копирование `apps/studio/harnesys-stub`.
