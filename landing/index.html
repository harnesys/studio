Self-hosted studio for AI agents that work in your folders

An agent gets tools for files, shell, git and web search, plus schedules, memory and plugins. It works inside your workspace on your machine, asks before anything risky, and you watch every step from an IDE-style interface in the browser.

Download — all platforms macOS (Apple silicon, Intel) · Linux · Windows
Or one line on a server: 
curl -fsSL https://raw.githubusercontent.com/harnesys/studio/main/scripts/install.sh | sh
harnesys up --with-ui

Every step in the open

The transcript is one readable feed: reasoning, each tool call with its input and exit code, the final answer. Streaming starts on the first token. Expand any call to see exactly what ran. Attach a screenshot by pasting it, branch the thread from any turn to try another route, and read per-turn token counts instead of guessing.

Agents are graphs, not prompts

An agent is a node graph: LLM calls, tool calls, map fan-outs, waits, interrupts where a human answers. Draw it on the canvas, then tune the twelve categories behind it — identity, model, compaction, limits, permissions, capabilities, skills, MCP, subagents, hooks and modes. Subagents spawn in a sandbox with reduced permissions; budgets cap steps, tokens and deadlines.

A real IDE in the same window

File explorer with per-line git status, Monaco editor, diff view, branches, staging and commits without leaving the tab. Terminals run in real PTY sessions next to the chat, and an LSP reports diagnostics in the status bar. The agent edits the same files you see.

It keeps working when you’re away

Schedules bind an agent, a thread and a permission mode to a cron, from presets like Weekdays to a raw expression. Webhooks wake a thread from an HTTP endpoint. Runs land in a dedicated log thread, past fires stay in a journal, and anything that needs a decision waits in the inbox with an unread counter.

And the rest of the toolbox

Rules you set once

Six operations — reading, writing, processes, network, MCP, agents — each get an allow, ask or deny gate, with presets from ask to bypass. Provider keys live in the macOS Keychain and never reach the browser; the web UI sits behind a token gate.

Memory across threads

Pins keep agent rules in context. Semantic memory stores editable facts. Episodic search looks through past conversations, and knowledge roots index your documents with hybrid full-text and vector search.

Bring your own model

Twenty providers connect out of the box, from OpenAI, Anthropic and Google to Ollama on your own GPU. Autodiscovery pulls pricing, context length and supported parameters; OpenRouter models sync from one dialog.

Plugins, skills, MCP

Installs Claude Code plugins and open Agent Plugins from git, npm or an archive. Skills load on demand, hooks fire on 37 events, MCP servers speak stdio, HTTP or SSE from a Cursor-compatible .mcp.json.

One desk, many machines

Pair another computer with a 6-digit code and the same window holds several hosts. Workspaces multiply, requests route to the right machine, and the layout follows the host.

Comfortable for hours

Dark, light or system theme, seven accent colors, four UI scales, custom git colors, chat font size and feed detail. Hotkeys everywhere; dialogs confirm before anything destructive.

Install

All platforms, today: macOS for Apple silicon and Intel, plus Linux and Windows builds.

Download

macOS DMG (Apple silicon and Intel) with the host bundled as a sidecar — drag to Applications and launch from the tray. Linux and Windows binaries ship the same three pieces: host, web gateway and the harnesys supervisor.

First launch on macOS: right-click the app and choose Open, or run xattr -cr /Applications/Harnesys.app — the build is ad-hoc signed.

Get the latest release

Linux server

installs to ~/.local/bin 
curl -fsSL https://raw.githubusercontent.com/harnesys/studio/main/scripts/install.sh | sh
harnesys up --with-ui

--install-systemd writes user units and starts them via systemctl --user. The web UI needs the Docker stack or the client-dist.zip asset with STATIC_DIR — details in the deploy docs.

Docker compose

host + web in one stack 
cp deploy/.env.example deploy/.env
docker compose -f deploy/docker-compose.yml up -d

The host writes its token into the shared volume on first boot and the web gate reads it automatically. Read it with docker compose exec host cat /data/config.json.

Connect another machine with harnesys host pair: a 6-digit code, valid for 10 minutes, entered under “Connect a new host…”. On the public internet, terminate TLS with Tailscale, Caddy or nginx and keep SSE unbuffered — recipes in docs/deploy.md.
