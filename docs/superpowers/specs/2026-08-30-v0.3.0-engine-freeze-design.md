# 0.3.0 Engine Freeze — Design Spec

**Scope:** docs `12-hitl-run-result`, `14-permissions`, `15-paths`, `20-session` + middleware behavior from `05`.
**Gate:** Permission/approve ask → respond → done; crash → load → resume; frozen surface table.

## 1. control:interrupt в graph.ts

**File:** `src/application/graph.ts`

Добавить ветку `node.type === 'control:interrupt'` в while-loop (после `control:goto`, перед `else`):

1. Читаем `reason` и `resumeSchema` из ноды
2. Генерируем `interruptId = crypto.randomUUID()`
3. Пишем snapshot: `status: 'needs_input'`, `cursor.interrupt = { interruptId, reason, resumeSchema, nodeId: cur }`
4. Yield event `interrupt.triggered`
5. Break из loop

`$output` не пишется. `$resume` = payload после resume; очищается при уходе с узла по ребру.

**Resume flow в graph.ts:**
- Принимает `resumePayload` и `startNodeId` (из `cursor.interrupt.nodeId`)
- Валидирует payload по `resumeSchema` (Ajv)
- Проверяет idempotency: same interruptId + same payload (canonical JSON) = no-op
- Записывает `$resume` в slots
- Продолжает execution с `startNodeId`

**Edge evaluation:** `evalWhen` уже читает slots. `$resume` доступен в slots после resume.

## 2. Permissions resolution

**File:** `src/application/permissions.ts` (новый)

```ts
function resolvePermissions(
  toolOperations: string[],
  callMap?: PermissionMap,
  sessionMap?: PermissionMap,
  runtimeMap?: PermissionMap,
): PermissionMap
```

4 слоя (карта заменяется целиком, не deep-merge):
1. `tool.operations` — список operations tool'а
2. `DEFAULT_PERMISSIONS` — fallback из пакета
3. `runtimeMap` — из `createRuntime({ permissions })`
4. `sessionMap` — из `session/send/run/start({ permissions })`

Резолв: `call ?? session ?? runtime ?? DEFAULT_PERMISSIONS`. Gate по каждой operation: любой `deny`/`ask` побеждает `allow`.

**Интеграция в tool-call.ts:**
- Перед execute каждого tool call: проверяем permissions для operations tool'а
- `deny` → `RunResult.status: 'failed'` (policy class)
- `ask` → `needs_input` / SessionEvent `ask` (source: `'permission'`)
- Порядок: permissions map → middleware `beforeTool` → intent/recorded + execute

## 3. Paths intersection

**File:** `src/application/paths.ts` (новый)

```ts
function resolvePaths(
  agentPaths?: PathsConfig,
  runtimePaths?: PathsConfig,
  sessionPaths?: PathsConfig,
): { allow: string[]; cwd: string }
```

3 слоя, всегда intersection (∩):
- `effective.allow` = ∩ всех заданных `allow` массивов
- `effective.cwd` = `session.cwd ?? agent.cwd ?? runtime.cwd ?? effective.allow[0]`
- `cwd` обязан лежать под `effective.allow` (иначе config error)

`ToolContext` получает `{ cwd: effective.cwd, paths: { allow: effective.allow } }`.

## 4. Session / AgentRun

**File:** `src/application/session.ts` (новый)

```ts
function createSession(
  agent: AgentDefinition | string,
  opts: { state?: RuntimeState; permissions?: PermissionMap; paths?: PathsConfig },
  runtimeCtx: RuntimeContext,
): SessionHandle
```

**SessionHandle:**
- `send(input, opts?)` → `AgentRun`
- `resume(opts?)` → `AgentRun`

**AgentRun:**
- `id: string` — runId
- `status` — `'running' | 'needs_input' | 'completed' | 'failed' | 'cancelled'`
- `stream()` — `AsyncIterable<SessionEvent>`, exclusive
- `output` — `Promise<{ text: string }>`
- `respond(askId, payload)` — → `Command.resume`
- `reject(askId, { note? })` — → `Command.reject`
- `cancel()` — → `Command.cancel`

**Guards:**
- `send` при live `running|needs_input` → `ThreadBusyError`
- `send` при pending `ask` → `PendingHitlError`
- `resume` при live `running|needs_input` → `ThreadBusyError`

**SessionEvent mapping из Event:**
- `run.completed` → `done`
- `run.failed` → `error`
- `model.completed` → `text-delta`
- `tool.completed` / `tool.intent` → `tool`
- `interrupt.triggered` → `ask`

**Crash recovery:**
- Snapshot `needs_input` в RuntimeState → `load` → `session(agent, { state })` → `resume()` → stream + respond

## 8. Gate criteria

1. Permission/approve ask → `respond({ approved })` → continue → `done`
2. Snapshot `needs_input` → новый процесс → `session({ state })` → `resume`
3. Frozen surface зафиксирован таблицей выше
