# Roadmap к рынку

**Date:** 2026-08-23

Статусы ядра `packages/harnyx` — [`docs/18-roadmap.md`](docs/18-roadmap.md). Этот файл — что должно стоять в продукте, чтобы Harnyx можно было поставить рядом с Claude Cowork, OpenClaw, n8n и Lindy и не выглядеть черновиком.

Критерий строки: человек платит или ставит это вместо соседнего продукта, потому что **агент делает работу часами и днями, ход виден, необратимое спрашивает, модели любые, процесс живёт без открытого окна**.

---

## Обещание

Harnyx — стол агентов на твоей машине (или на твоём VPS).

Агент привязан к папке. Его будят чатом, кроном или вебхуком. Он читает и пишет файлы, ходит в shell, MCP, браузер, навыки. Длинный ход не раздувает окно: уплотнение и артефакты. Между пробуждениями он помнит, что уже сделал: journal памяти. Перед удалением, отправкой, пушем, оплатой — пауза и кнопка. Весь ход — journal. Ключи твои.

Studio в репозитории — этот стол. `harnyx` — ядро, которое стол крутит.

## Конечная картина: что человек скачивает

Не `bun run studio` из клона. Продукт.

### Установка

Один из путей, все ведут в один и тот же хост:

- сайт → macOS / Windows / Linux: `.dmg` / `.msi` / AppImage
- `brew install --cask harnyx`
- `curl -fsSL https://harnyx.dev/install | sh` → CLI `harnyx`
- Docker: один контейнер, UI на порту, данные в volume

Первый запуск — мастер на три шага: ключ провайдера (OpenRouter / OpenAI / Anthropic / OpenRouter-совместимый / Ollama), папка workspace, имя агента. Через три минуты можно отправить сообщение. Расписание и вебхук — на том же экране, не в «настройках для взрослых».

### Как это живёт в системе

Два процесса с одной базой `~/.harnyx`:

| процесс | роль |
|---|---|
| **хост** | runtime, persist, cron, вебхуки, MCP, браузер, HITL-gate. Живёт в фоне. Старт с логином ОС. |
| **окно** | стол: чат, файлы, инспектор, inbox подтверждений, расход. Можно закрыть. |

Иконка в tray / menu bar: сколько агентов в `running`, сколько ждут `confirm` / `answer`, клик открывает inbox. Закрыл окно — хост не умирает. Уснул ноут — после пробуждения хост поднимает journal, `reconcileStaleRunning` / `resume`, очередь расписаний догоняет.

Тот же бинарь на VPS ($6 Hetzner). С ноутбука и телефона открываешь UI по HTTPS. Вебхуки смотрят в интернет. HITL приходит в Telegram / системный пуш. Это и есть платный тариф: always-on, публичный endpoint, не держать домашний компьютер.

### Что на экране в день запуска

Стол, который уже почти собран в Studio, доведённый до продукта:

- слева: workspace, агенты, файлы, расписания, вебхуки
- центр: тред, стрим шагов, дифф файлов, превью браузера, HITL-карточка
- справа: агент, skills, MCP, модель, расход
- сверху / tray: **inbox** всех ожидающих подтверждений по всем тредам, не только открытый чат
- длинный run: живая строка «шаг N, $X, токены окна, что делает сейчас»

Готовые стартовые агенты (ставишь в один клик, не пустой system prompt):

- ночной проход по папке/репо → утром дайджест, пуш только после confirm
- вебхук GitHub / Stripe / форма → подготовка ответа → confirm на отправку
- входящие файлы клиента → разбор, черновик, спросить перед внешним действием
- браузерный сбор (прайс, конкурс, кабинет) по крону → таблица в workspace

Skills и MCP — способ расширения. Стартовые агенты — то, что продаёт скриншот.

### Деньги

BYOK везде. Маржа с токенов не нужна на старте.

| что | цена |
|---|---|
| приложение на своей машине | бесплатно |
| хост, который крутим мы (VPS, HTTPS, вебхуки, бэкап journal) | **$29/мес** соло |
| несколько людей на один стол, общий inbox | **$79/мес** workspace |

Библиотека `harnyx` остаётся тем, что можно встроить. Стол — то, за что платят.

Дистрибуция запуска: сайт с 90-секундным роликом (крон → ход → confirm в tray), Show HN, один обзор «Cowork с любой моделью, кроном и journal». Без ролика длинный стол не продаётся.

## Обязательно

Без этого на рынок не выходить: соседние продукты это уже делают, или обещание «часы и дни» ломается в первый вечер.

### Долгий ход

Сейчас fold кладёт в модель весь journal, `maxSteps` по умолчанию 40, потолок денег в снимке есть, enforcement нет. Часовой run либо упрётся в окно, либо в 40 generation, либо в счёт.

| фича | зачем рынку | опора в каноне |
|---|---|---|
| **Уплотнение** | Cowork / Claude Code / длинные агенты живут сжатием хвоста. Без этого «часы» — демо на 15 минут. | контекст #6, fold |
| **Артефакты вне окна** | Лог shell, HTML, PDF, скрин браузера не едут в каждый `generate`. В окно — ссылка или выдержка. | контекст #7, `tool_result.outputFile` |
| **Потолок времени, токенов, `$`** | Автономный агент без крышки — страх номер один у тех, кто платит. Поля `RunConfigSnapshot.limits` довести до остановки хода. | лимиты 4a / 4b |
| **Обнаружение зацикливания** | Один и тот же tool с теми же аргументами, нет прогресса → стоп и запись в journal. Иначе «дни» = бесконечный счёт. | исполнение #5 |
| **Retry transient** | Сеть и 429 провайдера. Сейчас kind на шаге есть, маршрута retry нет. Соседние рантаймы это делают молча. | сбои #1 |
| **Fallback модели** | Поле на документе уже есть. При падении основной — запасная, ход тот же. OpenRouter / локальная как страховка. | модели #4 |
| **Смена модели на этом run** | Человек переключает на дешёвую/сильную без нового треда. | модели #2a |
| **Повтор шага** | Упал tool или generation — тот же шаг ещё раз, не весь ход сначала. | исполнение #8 |
| **Живой статус длинного run** | «Что делает, шаг, $, окно» в чате, в списке тредов и в tray. Refresh страницы ход не теряет. | stream + persist, уже почти |

Уплотнение пишет факт в journal (сжатый хвост остаётся восстановимым с диска). Память уплотнение не заменяет.

### Память и сборка окна

| фича | зачем рынку | опора в каноне |
|---|---|---|
| **Инструкции проекта в fold** | `AGENTS.md` / список путей. Поле `instructions.project` есть, fold не подмешивает. Без этого агент в репо тупой относительно Claude Code. | контекст #2 |
| **Pin + Semantic память** | Always-on pin и факты session/long через явные порты. Tools записи/чтения; человек видит и стирает в UI. Новый fire крона видит pin/long. | `docs/21-memory-ports.md` |
| **Episodic / Knowledge** | Поиск по истории (в т.ч. после уплотнения) и по корпусу доков — tools, не auto-RAG. | `docs/21` |
| **История расписания + память** | `scheduleFoldHistory` режет прошлые fire. После портов: last N ходов **и** pin/semantic.long в префиксе окна. | Studio schedules + `docs/20`/`21` |
| **Ветвление треда** | Тип `Journal.branch` есть, API и UI нет. «Попробуй иначе с этого места» — базовый жест ChatGPT / Cowork. | диалог #4 |

### Хост, который переживает ночь

Ядро stateless. «Дни» делает хост.

| фича | зачем рынку |
|---|---|
| **Хост отдельно от окна** | OpenClaw и Cowork живут, когда UI нет. `bun --watch` из репо — это стенд. |
| **Автоподъём после рестарта** | `reconcileStaleRunning` + `resume` есть. Хост сам вызывает их при старте, поднимает paused HITL и дожимает то, что можно. Очередь cron догоняет. |
| **Вебхуки стреляют** | UI и таблица уже есть, `SqliteWebhookRepo` в composition не подключён к прогону. Мёртвая кнопка на рынке выглядит хуже, чем отсутствие кнопки. |
| **Публичный URL вебхука** | Локальный хост: tunnel. VPS: HTTPS. GitHub/Stripe должны куда-то стучать. |
| **Очередь на занятый тред** | У расписаний уже есть. Вебхук и ручной `send` — тот же принцип, exclusive writer не ломаем. |
| **Секреты на хосте** | Ключи провайдеров, MCP env, tunnel token — не в промпт и не в git workspace. |
| **Бэкап `studio.db` + journal** | Один файл SQLite. Копия по крону / в тариф хоста. Потеря хода за неделю убивает доверие. |

### Человек в контуре

HITL в ядре уже сильный. Продукт вокруг него тонкий: карточка только в открытом чате, Plan disabled, mid-run человека нет.

| фича | зачем рынку |
|---|---|
| **Inbox подтверждений** | Все `awaiting_confirm` / `awaiting_input` по workspace, с tray badge. Как очередь ревью, не как прятки в треде. |
| **Plan mode** | Слот в композиторе уже есть. Режим, в котором агент не пишет файлы и не делает побочных эффектов, пока человек не подтвердит план. Claude Code этим продаёт доверие. |
| **Сообщение на ходу** | Пока run живой, человек вставляет реплику. Сейчас exclusive writer + нет mid-run human. Без этого «автономный» агент глухой на часы. Канон: не ослаблять одного writer — очередь на этот тред, вливание в ход по правилу interrupt. |
| **Перехват** | Стоп текущего намерения, новая инструкция, тот же тред. |
| **Уведомление, когда ждут человека** | ОС + звук. Иначе always-on стоит в paused до утра, работу «днями» никто не видит. |
| **Confirm с другого устройства** | Тот же хост, UI с телефона: inbox и две кнопки. Для VPS это must, для десктопа — must, если обещаем ночные прогоны. |

Автономия — режим `auto` / `bypass` плюс узкий `ask` на необратимом. Inbox и уведомление — как человек вообще успевает быть в контуре.

### Действия, без которых сравнение сливается

| фича | зачем рынку |
|---|---|
| **Браузер** | Cowork, OpenClaw, Eigent. Агент без браузера в 2026 — чат с файлами. В корне уже `playwright-core`. Действия: открыть, клик, тип, скрин, snapshot DOM. Confirm на навигацию к внешнему / сабмит. Скрин — артефакт. |
| **Git как действие** | Workspace уже знает folder/git, dirty, branch. Нужны status / diff / log / commit / push с HITL на commit и push. Shell+«не забудь» недостаточно: Claude Code выигрывает этим жестом. |
| **Песочница shell** | Рабочий корневой FS + blocklist есть. Для рынка нужен режим: процесс в jail / отдельном worktree / контейнере, сеть по политике. Иначе «агент с shell на диске» не ставят на важные папки. |
| **Таймаут на контракте tool** | Сейчас у shell/http. Общее поле на `ToolSpec`, иначе браузер и MCP висят часами. |
| **Дифф правок в UI** | Агент пишет файлы — человек видит патч до/после, не только путь в tool line. |

### Поверхность продукта

| фича | зачем рынку |
|---|---|
| **Онбординг** | Ключ → discover моделей → агент → первый `send`. Сейчас gate workspace и settings как у внутреннего стенда. |
| **Стартовые агенты и skills** | Три-четыре готовых сценария из раздела упаковки. Пустой стол = человек не понимает, зачем ставил. |
| **Поиск по тредам и journal** | Неделя работы агента без поиска — мёртвый архив. |
| **Расход на столе** | Карточка usage в композиторе уже есть. Нужны: день / агент / тред, потолок, предупреждение до крышки. |
| **Ошибки провайдера языком человека** | 401, квота, модель снята, Ollama не запущен — что нажать. |
| **Вебхук end-to-end в UI** | Создал → виден URL → тестовый ping → тред с journal. |

## Желательно

Имеет смысл успеть до публикации, если ещё есть скорость. Это то, чем ревьюер на HN добьёт «почти», и то, чем OpenClaw / Lindy забирают привычку.

| фича | зачем рынку |
|---|---|
| **Канал Telegram (и по возможности Slack)** | OpenClaw вырос на «агент в мессенджере, которым уже пользуюсь». Hitl + короткий `send` в том же боте. Десктоп не отменяет канал: ночью человек смотрит телефон. |
| **Субагент / child journal** | Длинный ход дробит работу: исследование в child, в родителя — выдержка. Форма в `docs/11-deferred-and-freeze.md`. Иначе уплотнение одно на всех и окно снова лопается. |
| **Починка JSON и structured output** | Инструменты и финальный ответ по схеме. Флаг `structured` в discover уже есть. Меньше «агент сломал аргументы на шаге 80». |
| **OAuth коннектора MCP** | Gmail / GitHub / Notion без ручной вставки token в `mcp.json`. Без этого «подключи почту» проигрывает Lindy. |
| **Отложенная загрузка tools** | Большой MCP не занимает окно целиком. Skills уже грузят текст по имени — тот же жест для tools. |
| **Верификация шага** | Отдельный вызов модели перед опасным внешним действием. Дорого, но для push/send/pay — аргумент доверия. |
| **Связка run → run** | «Когда закончишь разбор, запусти рассылку-черновик». Канон: отложенный запуск / wake. Расписания частично закрывают, явной связки нет. |
| **Шаблоны вебхуков** | GitHub push, Stripe event, form POST — пресеты payload → prompt. Сырой endpoint для гиков, пресет для покупки. |
| **Экспорт journal** | JSON / markdown хода. Аудит для клиента услуг и для себя. |
| **Обновление приложения** | Sparkle / auto-update. Без этого раздача `.dmg` умирает на второй неделе. |
| **Кастомный tool в UI** | HTTP-действие с схемой, без правки репо. Мост к n8n-аудитории, которым не нужен граф, нужен один вызов. |
| **Голос / диктовка в композитор** | Мелочь, Cowork-класс ощущений. Не ядро. |

Мультиагентный «оркестр из семи ролей», граф-холст как главный UX, RAG-платформа, eval-облако, A/B, feature flags, tenant isolation «как у Salesforce» — это соседние продукты. Сюда не тащить даже при скорости: ценность стола в ходе, памяти, HITL и том, что процесс жив.

## Упаковка: что сделать руками, не «фича агента»

Это тоже выход на рынок, не хвост после кода.

1. **Имя и сайт.** Один экран: обещание, ролик, download, BYOK, цена хоста. Документация: install, первый агент, cron, webhook, HITL, свои ключи.
2. **Бинарь хоста + UI.** Сейчас dev: порт 3000 + Vite 5173. Продукт: один процесс раздаёт API и собранный клиент, как `bun server` в production, плюс отдельный daemon-режим без окна.
3. **Трей и автозапуск ОС.** macOS launch agent / Windows service / systemd user.
4. **Туннель из UI.** Кнопка «дать URL для вебхука» (cloudflared или свой). Без CLI-танцев.
5. **Лицензия.** Ядро `harnyx` — открытое (чтобы встраивали и писали). Стол — исходники в этом репо, деньги за hosted и за удобство always-on. Об этом сказать на сайте прямо.
6. **Тестовый контур перед публикацией.** Один ночной агент на этом же репо три дня подряд: уплотнение не ломает ход, память переживает fire, HITL доходит в tray, рестарт хоста поднимает paused, счёт не улетает за потолок. Если это не прожито у себя — не анонсировать «часы и дни».

## Порядок работ

Не фазы продукта. Зависимости, чтобы не строить UI на пустом ядре.

1. Уплотнение + артефакты + enforcement лимитов + retry/fallback/loop-detect — иначе любой длинный сценарий вранье.
2. Порты памяти (Pin / Semantic / Episodic) + project instructions в сборке окна + ветвление — иначе крон и «дни» пустые. (`docs/20`, `docs/21`)
3. Хост-демон, автоподъём, вебхуки с огнём, туннель, секреты, бэкап.
4. Inbox, plan mode, interrupt, уведомления, confirm с телефона.
5. Браузер, git-действия, дифф, песочница shell.
6. Онбординг, стартовые агенты, поиск, расход, e2e вебхук в UI.
7. Упаковка бинаря, tray, сайт, ролик, Telegram, child journal — сразу, как 1–6 уже гоняются у себя ночью.

Пункты 1–6 — стол, за который не стыдно взять деньги. Пункт 7 — чтобы человека вообще привели к скачиванию и чтобы ночью HITL не гнил в закрытом ноуте.

## Рыночная проверка готовности

Можно анонсировать, когда все три правдивы:

- Агент на этом репозитории работает **часами** в одном run: окно не лопается, $ не улетает, после рестарта хоста ход продолжается или честно failed с journal.
- Расписание **днями**: каждый fire видит память, не дублирует вчерашнюю работу, необратимое приходит в inbox.
- Незнакомый человек ставит с сайта **без клона репо**, за три минуты получает первый ход, за пятнадцать — крон или вебхук.

Пока жив только `bun run studio` из checkout — это стенд разработки библиотеки. К рынку он становится, когда хост, окно и обещание длинного хода совпадают.
