# Harnesys 0.2.0 design — executable graph (hybrid Harnyx reuse)

Date: 2026-08-30
Scope: `docs/06`–`11` + wiring `05`/`04`; gate 0.2.0 hello-world `llm → tool → end` on `InMemoryRuntimeState`.
Approach: **Hybrid C** — reuse Harnyx tested modules for 06–07/discover/expr where exists, rewrite graph executor natively per SoT Snapshot/Cursor.

## Goals / Non-goals
Goals: ProviderConfig|ModelsPort binding + `tool()` registry + `toolMessages` policy + `defineAgent` structural checks + `rt.compile`/`rt.check` codes + `run`/`start` graph (`core:start`/`end`, `llm:generate` one call per node, `tool:call` fixed/batch + approve sugar normalized, `control:assign` replace, `control:goto`, edges first-wins) + reducers `replace|merge` + commit `recorded` (and `intent` for financial/destructive per 04).
Non-goals: `control:spawn`/`handoff`/`interrupt`, permissions/middleware HITL (0.3), skills/mcp/artifacts (0.4), stream `model.chunk` batching durable (09 STREAM_* only live Iterator shape in 0.2), `ai/@ai-sdk` public exports.

## Architecture
Clean: `domain` (pure types/checks), `ports` (contracts `04–06`), `application` (compile/check/graph), `adapters` (InMemoryState + private ai adapter + discover). File cap 300 lines; type-indexed access banned; FSD barrel via `index.ts`.

```
packages/harnesys/src/
  domain/{agent-definition,expr,json-schema,snapshot,errors,run-result,middleware}.ts
  ports/{models,tools,runtime-state,create-runtime,mcp,skills,artifacts,session,permissions,paths}.ts
  application/{expr-eval,validate,compile,check,graph,llm,tool-call,create-runtime}.ts
  adapters/{in-memory-runtime-state,models/discover,catalog,ai-llm-adapter}.ts
```

## Models (06) — Harnyx reuse
Source: `Harnyx/packages/harnyx/src/domain/types.ts` (DRIVERS, ModelRecord/ProviderConfig/ModelBinding/ModelsPort/DiscoverInput), `domain/driver.ts:isDriver`, `domain/resolve.ts:liftHostFields,resolveModel`, `application/get-binding.ts:normalizeProvider,bindingOf,toBinding`, `adapters/discover/*` + `application/discover-models.ts` + `adapters/discover/registry.ts`.
Harnesys port `src/ports/models.ts`: keep `ProviderConfig`, `ModelRecord`, `ModelsPort`, `Provider` shape identical except remove `private` nuance; add `ModelsApi = ModelsPort & { discover }`. `createRuntime({models})` accepts `ProviderConfig[]` (normalized) or `ModelsPort`. Binding table per 06: `llm.model` omit|'default'→`agent.model`, string→`models[id]`, AgentModelRef as-is; unresolved→`model_unresolved` (08). Private `ai` drivers inside `adapters/ai-llm-adapter.ts` wrap `ai` streamText; public exports never re-export `ai`.

## Tools (07) — adapted Harnyx define-tool
Source: `Harnyx/src/domain/tool.ts` (Zod) + `application/define-tool.ts`. Harnesys `src/ports/tools.ts`: `ToolDefinition {name,description,group?,operations?,input:JsonSchema,execute(input,ctx),sideEffect?}`, `ToolContext {cwd,paths:{allow},signal?,artifacts?}`, `SideEffect` union per 07. Factory `tool(name,spec)` validates name/description presence (structural), stores `input`. Runtime validates args via Ajv before `execute`; `execute` receives parsed/coerced input. Registry in `createRuntime`: Map `name→def`, collision host vs MCP → error at startup (deferred to 0.4 for MCP). `llm:generate.tools` and `tool:call.name` resolve against registry; miss→`tools_unresolved`. Order: permissions→beforeTool intent/recorded — only registry part in 0.2.

## Validate / compile / check (08)
`defineAgent` (domain) : throw aggregated `ValidationError {code,message,path}[]` on structural codes: `id_required,version_format,start_count,end_count,edge_endpoint,outgoing_required,missing_default,default_edge,prompt_missing,tool_call_shape,barrier_policy,goto_target,expr_syntax,cycle_budget,messages_path,concurrent_replace` warnings `spawn_targets_dynamic,output_key_reserved,unreachable`. Non-throw path kept for `rt.compile`.
`rt.compile(def): { plan, diagnostics: {code,severity,path}[] }` — pure, no I/O, no binding probe; builds `plan {nodes:Record<string,PlanNode>, edgesByFrom:Map, order}`. Reuses structural validators.
`rt.check(def): { diagnostics }` — with runtime maps: `tools_unresolved,model_unresolved,unsupported_node,duplicate_hitl`, plus `handoff_target` stub. Implementation in `application/compile.ts` + `check.ts`; `defineAgent` delegates to same validators then `JSON.parse(JSON.stringify)` on success (0.1 behavior retained).

## Expr / edges / messages (03, 08)
`application/expr-eval.ts`: no `eval`/`Function`. Tokenize + parse for Path (`$input,$state,$output,$resume` + `.` `[index]` `["key"]`), ops `= != > < >= <= ! && ||`, parens, literals, functions `exists(path)`, `length(path)`, substitution `{$path}` in prompts via `JSON.stringify`. `expr_syntax` on parse fail, `unknown_path` at evaluate, `expr_path` when `compile` can derive schema/state path statically (08). Evaluation context `{input,state,output,resume}`.
Edges first-wins per 03: partition by `from`; ≤1 default last; `missing_default`/`default_edge` structural; runtime `no_matching_edge`. `core:start`: evaluate `state.initial` once under `$input`; `$output={input}`. `messages` field: must be `$state.*` else `messages_path`; if target undefined initialize from `$input.messages` if Array else `[]`; llm assistant + subsequent tool results append to that path (see graph).

## Graph core — run / start / llm:generate (09)
`application/graph.ts`: `GraphRunner { run(agent,input,state,permissions?,paths?):RunResult; start(...):AsyncIterable<Event> }`. `run` consumes `start` until terminal or `needs_input`. One `llm:generate` = one model call. Snapshot shape per 04: `{sessionId,runId,definitionHash,planHash,sequence,status,runtimeVersion,initialInput,state,cursor,artifacts}`; `runId` fresh per run; `nodeExecutionId = ${runId}:${nodeId}:${n}`; `idempotencyKey=${sessionId}:${nodeExecutionId}:${attempt}` (stored for tool execute replay). Cursor holds `{currentNodeId,stepPhase:scheduled→executing→recorded|unknown|failed, results buffers}` and `steps/tokens` counters for `budget.maxSteps|deadlineMs` → `budget_exceeded`.
`llm:generate` contract: resolve model via 06 binding; load `prompts[prompt]` + substitute `{$…}`; evaluate `messages` Expr; call private `ai-llm-adapter` (drivers `openai, anthropic, google, mistral, xai, minimax, alibaba, moonshot, openai-compatible, ...` reused). Output `$output={finishReason,text,toolCalls,...structured}`; if `finishReason==='tool-calls'` do not auto-execute — edge to `tool:call`. Stream: live iterator emits `Event {type:'model.delta'}` per chunk; durable commit writes single `model.completed` recorded (09 Fig). AbortSignal forwarded.

## tool:call (10) + control:assign/goto (11)
`application/tool-call.ts`: Fixed `{name,args:Record<Expr|unknown>}` sugar to `calls=[{name,argsEvaluated,id}]`. Batch `{calls:Expr, concurrency:Expr|'parallel'|'sequential', barrier:{policy:'all'} default, approve?}`. Normalize: evaluate `calls` Expr → array length check vs `tool_call_limit` 32 → `tool_call_limit`; `concurrency` resolve literal vs Expr string else `concurrency_invalid`. `parallel`: `maxConcurrency = min(calls.length, host.maxToolConcurrency ?? len)`; `sequential`:1. `barrier.policy` only `'all'` else `barrier_policy`. Execution: `intent→execute→recorded` per `sideEffect` table 04 (pure/read→recorded; write/communication→recorded; financial/destructive/credentialed→intent then recorded). Commit per tool result slot `recorded`; crash after `intent` without `recorded` → `unknown` (Phase known). Result buffer index-ordered: `$output.results[{id,name,result,isError,skipped?,cancelled?}]`. Abort/cancel per call → slot `cancelled`. `$output.results` before barrier → `output_not_ready`. Flush to `$state.messages` at barrier per `toolMessages`: `'barrier'` single append, `'ordered'` per index; if llm has no messages path → no flush; assistant already in messages before batch. `approve` barrier (10): split `needsApprove` vs `free`, sequential needsApprove, `skipped` on `approved:false`, `interruptId=batch/{nodeExecutionId}/{callIndex}` (deferred interrupt node to 0.3 but approve sugar compiled here).
`control:assign` (11): `patch:Record<Expr|unknown>` evaluate each key, write `$state` via `replace` per key, `$output={patched:string[]}`. `messages` only if `patch.messages` present. Parallel writers from future spawn → `concurrent_write` only if `reducers[key]==='replace'` and ≥2 writers; merge or omit ok (checked compile `concurrent_replace`).
`control:goto`: evaluate `target` Expr → string id else `goto_target_missing`; jump without when; do not write `$output`; endpoint not validated structurally.

## createRuntime wiring (05) — 0.2 delta
`createRuntime({models,tools?,agents,middleware?,toolMessages,mergeState?})` builds registry, validates tool collisions, stores `mergeState` override per key for reducers, default `toolMessages='barrier'`. `RuntimeHandle` now implements `run/start` (execute), `compile`/`check` (delegate), `session/reload* /close` remain NotImplementedError until 0.3/0.4. `run`/`start` need `state:RuntimeState` + optional `permissions`/`paths` overlay; `resume` remains stub.

## Error taxonomy
Reuse `NotImplementedError` + `ValidationError` with `code` union from 08 table. Runtime throw codes: `concurrency_invalid,unknown_path,goto_target_missing,spawn_target_missing,tool_call_limit,output_not_ready,no_matching_edge,budget_exceeded`. Model: `model_unresolved`. Tool: `tools_unresolved`. All codes serialized in `RunFailed {reason, code?}` per 12 shape (but 0.2 `RunResult` still `success|failed|needs_input` minimal).
